# World Defense
Portrait mobile tower-defense / strategy project built with Godot 4.5.1.

Implemented source foundations include 250 generated campaign stages, exactly five waves per battle, variable biomes/routes/bridge flags, tower and mobile army progression to level 100, adaptive counter-composition, six-hour offline production cap, persistent save data, five localization targets, and Android export automation.

Opening rule: the boot screen contains only **Ahmet Eray Ölçer** before entering the game.

A Play release build still requires final production assets, complete gameplay/UI integration, QA, and release signing.
